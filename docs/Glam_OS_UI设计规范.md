# G'lam OS UI 设计与排版规范

> 适用于 G'lam OS 320×240 横屏嵌入式系统界面（桌面、状态栏、控制中心、内置应用及弹窗）。

---

## 核心文字与排版铁律（必须严格遵守）

1. **极简文字原则**
   - 所有的字都要尽量减少，**尽量不写字，除非必要**。
   - 能用图标表达的控件（如 Dock 栏、状态栏、播放控制）一律只放图标，不配文字。
   - 必须保留的应用/功能名称尽量压缩至 2 个字（如 `音乐`、`时钟`、`计算`、`文件`、`设置`、`应用`、`控制`、`后台`）。

2. **严禁并排 / 并列 / 多列文字**
   - 所有字体元素**不允许做成并排、并列、多列**排布。
   - 同一卡片或信息块内的多个文本项必须**纵向单列分行**居中或对齐排布，禁止左右拼挤（例如日期与星期必须分别独占一行，禁止图标与文字横向并排）。

3. **非必要不写原则**
   - 没必要的说明文字、引导语、副标题、状态装饰文案**一律不写**。
   - 禁止出现如 `待机 25m`、`系统就绪`、`点此选歌播放`、`音频待命`、`上滑或点此收起` 等冗余文案。

## 首页（Launcher）布局规范

- **顶部状态栏（320×24）**
  - 左侧：仅保留时间（`HH:MM`）。
  - 中间灵动岛：空闲时收起为无文字极简胶囊；仅在音乐播放或专注计时运行时展开显示必要信息。
  - 右侧控制中心入口：仅保留必要状态图标（Wi-Fi / TF 卡），不显示冗余内存数字。
- **第 1 页左侧**
  - **左上时钟卡片（150×74，占 2×1 格）**：大号时间居中置顶，下方日期与星期合并居中显示在同一条横线上（如 `11月22日 周日`）；移除待机时间标签。
  - **左下区域（150×74，占 2×1 格）**：默认留白（取消原音乐播放插件），透出高斯模糊壁纸；编辑模式下可自由拖入应用图标或时钟组件。
- **桌面全局编辑模式（类手机交互）**
  - 长按桌面任意应用图标、时钟组件或 Dock 栏图标，即进入全局编辑模式；
  - 支持跨页与跨 Dock 栏自由拖动排序/交换（拖至屏幕左右边缘自动翻页）；
  - 支持点击左上角红 `-` 徽标移除（第三方 `.gla` 应用支持移除或卸载）；
  - 支持编辑模式下点击任意槽位直接修改/替换，或点击顶部 `+` 添加已移除的应用与组件，点击 `完成` 自动持久化保存至 NVS。
- **第 1 页右侧（2×2）与第 2 页（4×2）**
  - 图标在上、极简 2 字名称在下（纵向单列）。
- **底部悬浮 Dock 栏**
  - 纯图标居中展示，**不写任何文字**。
